Respaldo de mi clóset

Los datos se guardan en este navegador y dispositivo, no en GitHub. Si borras los datos del navegador o cambias de iPhone, podrías perderlos. Exporta un respaldo periódicamente.

Las fotografías se incluyen en el respaldo, por lo que puede ocupar bastante espacio. Importar reemplaza los datos actuales, previa confirmación.

Uso gratuito

Esta versión no requiere suscripción ni cuenta. Para mayor compatibilidad, ábrela desde GitHub Pages en lugar de abrir el archivo local. Haz un respaldo después de registrar las primeras prendas. El almacenamiento local no sincroniza entre navegadores ni dispositivos.
